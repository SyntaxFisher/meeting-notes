# Meeting Notes 2.1.3

- One-click agent setup works when `~/.local/bin` is not on the login shell’s PATH. The agent registers Meeting Notes by the app’s full path, so Codex in ChatGPT Desktop finds it without shell configuration.
- The `meeting-notes` command is available in new terminal sessions: on launch from Applications, the app adds `~/.local/bin` to the zsh login profile if it is missing.

Requires an Apple silicon Mac with macOS 26 or later.
