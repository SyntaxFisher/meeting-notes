# Meeting Notes 2.3.0

- **Export Diagnostics…** saves everything about one meeting as a zip file for debugging. It is in a meeting's context menu in the Library and in the **Meeting** menu, works for meetings in every state, and contains the meeting's audio, transcript and record, an unfinished capture, the captured tracks and Teams trace kept for replaying the meeting, the diagnostic log around it and the settings, with a manifest of versions and of anything that was not available. The command line offers the same as `meeting-notes export-diagnostics <id> <out.zip>`.

Requires an Apple silicon Mac with macOS 26 or later.
