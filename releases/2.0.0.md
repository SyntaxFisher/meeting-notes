# Meeting Notes 2.0.0

- Ask your coding agent about your meetings through the built-in MCP server. Connect Codex, Claude Code or pi in Settings, search transcripts, and open meetings or specific passages from links.
- Browse a searchable meeting library with audio playback, editable transcripts and speaker names, and short summaries beneath meeting titles.
- Let agents name untitled meetings, summarize meetings and correct clear transcription errors while working with them. Each automatic suggestion is optional; changes you explicitly request remain available.
- Transcribe locally with Whisper large-v3-turbo, including German, English and mixed-language meetings. Improve short recordings, microphone capture and speaker identification.
- Keep recording while earlier meetings transcribe. Retry interrupted work, discard immediately, and receive quiet sounds for recording and transcription events instead of macOS notifications.
- Keep all transcripts. Choose whether to retain audio, with a configurable 10 GB default limit, and manage saved meetings in Settings.
- Simplify onboarding and settings, add Documents permission to setup, and improve transcript scrolling and window sizing.
- Open meeting links using HTTPS Universal Links. Existing native meeting links continue to work.

Existing recordings and transcripts stay in `~/Documents/meeting-notes`. Models download on first transcription; processing runs locally. Restart connected agent clients after updating to load the new MCP tools.

Requires an Apple silicon Mac with macOS 26 or later.
