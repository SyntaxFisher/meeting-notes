# Meeting Notes 2.1.0

- Agents find more in long meetings. `search_meetings` now takes `queries`, a list of alternatives such as `["kost", "budget", "cost"]` searched in one call, so synonyms, word forms and both meeting languages need one search instead of many.
- The MCP server now tells agents that search is literal: they search with word stems and translations, and read the whole meeting when you ask for everything on a topic or when searches find little. In tests with a two-hour meeting, Claude and Codex agents found every answer, including ones phrased differently from the question, with about half the tool calls.
- Meeting details for agents no longer include `transcript_path`. Agents read and edit transcripts through the MCP tools; `recording_path` remains while the audio exists.

Agents that call `search_meetings` with the old `query` parameter get an error and should pass `queries` instead.

Requires an Apple silicon Mac with macOS 26 or later.
