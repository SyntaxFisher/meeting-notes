# Meeting Notes 2.0.1

- Name every meeting file after the meeting's UTC start time, such as `20261105T141700Z.txt`, without spaces or titles. Titles now live only in the app and the meeting record, so renaming a meeting never renames its files.
- Rename existing meetings to the new scheme automatically the first time the app, the command line or the MCP server reads the meetings folder. Meetings from 1.x get a record that keeps their title. Summaries and other extra files keep their suffix, and nothing is overwritten.

Meeting ids change with the new names, so meeting links and ids from earlier versions no longer open a meeting; ask your agent for a new link. Automation events no longer include `stem`, and the command line no longer accepts old file names.

Requires an Apple silicon Mac with macOS 26 or later.
