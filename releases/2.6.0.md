# Meeting Notes 2.6.0

- Export Diagnostics has a new Split into chunks option. A zip larger than 49 MB is saved as numbered parts (`.zip.001`, `.zip.002`, ...) that fit common upload limits; `cat <name>.zip.* > <name>.zip` joins them again. On the command line, `export-diagnostics` takes `--split`.
- `MeetingNotes --help` prints the command-line usage instead of starting the app.

Requires an Apple silicon Mac with macOS 26 or later.
