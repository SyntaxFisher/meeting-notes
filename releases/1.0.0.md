# Meeting Notes 1.0.0

- Signed and Apple-notarized installer with a clear drag-to-Applications layout.
- Automatic updates from GitHub, with manual checking and an automatic-update toggle.
- Update checks and restarts wait for recording, transcription, and permission setup to finish.
- Includes the native local transcription and speaker-detection engine.

Requires an Apple silicon Mac with macOS 26 or later. Install in Applications and use Grant Permissions for microphone, system audio, and Accessibility access. Speech models download on first use.
