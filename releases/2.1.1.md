# Meeting Notes 2.1.1

- After an update from an earlier version, the panel and Library say **Updating meetings** while meetings are converted to the current file names, instead of *Waiting for access to Documents*. Converting many meetings can take a few minutes. Setup and Settings show Documents as **Allowed** meanwhile.
- The setup window opens once after updating from a version that did not have it, so you can review the preferences and connect a coding agent. Afterwards it opens by itself only when a permission is missing.

Requires an Apple silicon Mac with macOS 26 or later.
